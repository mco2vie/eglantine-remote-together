# License and distribution notice

This repository is an unofficial documentation and source-patch project.

## Do not add or host

Do not commit, release, upload, or host:

- `steam_api64.dll` or any other Steamworks SDK binary;
- the Steamworks SDK or its headers/import libraries;
- a generated Eglantine build made with the Steam Remote Play feature;
- emulator keys, game files, game dumps, firmware, shaders, screenshots containing game content, or user logs containing private information.

Do not publish instructions that encourage users to run this patch under an App ID they do not own or are not explicitly authorized to use.

The included Patch & Build wizard deliberately contains no Steamworks SDK material. Users must obtain Steamworks access themselves through Valve, use an App ID they are authorized to use, and create a private local build.
