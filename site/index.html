Before the first build

What you need

You only prepare two things yourself. The wizard checks your PC and gets every other free tool for you, after asking.

  1. The Steamworks SDK zip (version 1.62 or newer), downloaded with your Steamworks account. Keep the zip as it is: the wizard unzips it and usually finds it in your Downloads folder by itself.
  2. A Steam App ID that you own or are expressly authorized to use, configured for Remote Play Together.
  3. Windows 10 or 11, 64-bit, an internet connection, and about 25 GB free the first time (15 GB if the Microsoft C++ compiler is already installed).
Installed or downloaded for you when missing: the Microsoft C++ compiler (free Visual Studio Build Tools, about 8 GB, from Microsoft's signed installer; Windows asks for administrator approval once), Git, Qt 6.8.3 with Qt Charts, and the glslang shader compiler. Qt, Git and glslang go into the build folder only, so they do not change the rest of your PC. Advanced users can still pick their own Qt or Vulkan SDK folders.

Build a version or fork

Four steps

  1. 1

    Download and extract

    Download the builder zip, extract it, then double-click Eglantine-Steam-Remote-Play-Builder.exe.

  2. 2

    Choose the source

    For official Eglantine, keep https://github.com/Eglantine-Community/Eglantine.git. Choose Branch or Release tag, then pick a name from the list: the default branch (nx2) is preselected, and a release tag such as v0.1.0-rc3 is a fixed version.

  3. 3

    Let the wizard check your PC

    It shows what is ready and what it will get for you. Keep Install the Microsoft C++ compiler for me ticked if it is missing. Then select the Steamworks SDK zip (or let the wizard find it) and enter an App ID you own or are expressly authorized to use, configured for Remote Play Together. The builder never changes your existing Eglantine installation.

  4. 4

    Finish and wait

    After you click Install, the wizard itself shows each step (“Step 1 of 6”…) with a progress bar and the live log. The first build can take one to two hours, mostly downloads and compiling. When it is done, a button opens the folder with your new eglantine.exe. If something fails, the red message says what to fix, and running the builder again keeps what was already downloaded. Later builds only compile what changed, so they are much faster.

For a fork: paste its public GitHub HTTPS URL and the exact branch or tag. Only build a fork you trust: its CMake build can run repository-controlled commands on your PC. The builder stops without changing your normal Eglantine install when the patch does not fit.

Troubleshooting

If something does not work

The patch does not apply to my fork.

The builder stops safely without changing your normal Eglantine install. Send the last-build-failure.json file and the log path printed in the PowerShell window. Do not send keys, game files, or your Steamworks SDK.

A friend’s controller appears but does nothing.

Press Shift+Tab, open Steam Controller Settings, and select a Gamepad template for each controller. The controller layout comes from the authorized application's Steam configuration.

Player 1's controller stopped working.

Turn on the host controller before guests join. If necessary, open Eglantine controls and select Player 1's controller again. The patch also tries to restore Player 1 when Steam replaces the original controller.

Steam says it cannot connect or refuses the App ID.

Use an App ID you own or are expressly authorized to use, and ensure its owner configured it for Remote Play Together. Check the account and App ID with that application's Steamworks owner.

Dépannage

Si quelque chose ne fonctionne pas

Le patch ne s'applique pas à mon fork.

L'outil s'arrête sans modifier votre installation Eglantine normale. Envoyez le fichier last-build-failure.json et le chemin du journal affiché dans la fenêtre PowerShell. N'envoyez pas vos clés, vos jeux ni votre SDK Steamworks.

La manette d'un ami apparaît mais ne fait rien.

Appuyez sur Maj+Tab, ouvrez les paramètres de manette Steam et choisissez un modèle Gamepad pour chaque manette. Le profil de la manette vient de la configuration Steam de l'application autorisée.

La manette du joueur 1 ne fonctionne plus.

Allumez la manette de l'hôte avant que les invités rejoignent la session. Si besoin, ouvrez les contrôles Eglantine et sélectionnez à nouveau la manette du joueur 1. Le patch essaie aussi de restaurer le joueur 1 lorsque Steam remplace la manette d'origine.

Steam ne se connecte pas ou refuse l'App ID.

Utilisez un App ID que vous possédez ou que vous êtes expressément autorisé à utiliser, et vérifiez que son propriétaire l'a configuré pour Remote Play Together. Vérifiez le compte et l'App ID avec le propriétaire Steamworks de l'application.

Privacy

No analytics or account collection

This static page has no analytics, advertising, contact form, or tracking service. It stores only your chosen page language in your browser's local storage.

To get missing tools, the builder downloads only from Microsoft (Visual Studio Build Tools), GitHub (Git, glslang, aqtinstall, and the source you chose) and Qt's official servers. Each download is checked against a fixed SHA-256 or Microsoft's signature.

The builder itself does not upload emulator keys, game files, Steamworks SDK files, or generated builds. The selected source can run its own build commands and network requests, so choose only a repository you trust and do not put private files in the build workspace.
